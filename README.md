# Campus Classroom Availability Finder

## Problem Statement
Students and faculty may need to quickly find an available classroom or laboratory with sufficient capacity and required facilities.

## Objective
To create a simple browser application that filters rooms according to day, time, capacity, and facilities.

## Features
- Search rooms by day
- Search by time
- Specify minimum capacity
- Filter by facilities
- Display matching classrooms and labs

## Technologies
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
campus-classroom-availability-finder/

```

## How to Run
Open `index.html` in a browser.
